# Hero build timelapses

Each service page can play a scroll timelapse like the homepage's. The hero
opens on the finished job (the service's photo), and the first scroll wipes it
away to reveal day one. Then the build plays forward, one "day" per frame,
with an HB Links crew at work. They're illustrations, not real projects.

| Sequence | Frames | Story |
|---|---|---|
| `adu` (homepage) | 23 | done |
| `bathroom-remodel` | 9 | old bath → demo → waterproofing → tile → finished |
| `deck-and-patio` | 9 | old slab → base and forms → pavers → pergola → finished |
| `garage-conversion` (ADU page) | 10 | old garage → door out → new front wall → finished rental unit |
| `kitchen-remodel` | 10 | old kitchen → gutted → rough-in → cabinets → finished |
| `home-remodel` | 11 | closed-off rooms → wall out → new beam → finished |
| `home-additions` | 12 | backyard → slab → framing → sunroom built around the camera |
| `design-build` | 12 | a blueprint on a table, the house drawn stage by stage (generated by `design-build/blueprint.mjs`, not Gemini) |

The prompts for each are in `<sequence>/PROMPTS.md`.

## How it works

1. **The last frame is your service photo.** It's already in place as
   `<sequence>/keys/NN.png` and `<sequence>/frames/NN.png`.
2. **Make the keys, walking backwards.** A key is one day of the job with no
   people in it. Edit the photo back one stage at a time, in the order the
   PROMPTS file lists them, so the camera and the room never change. Save
   each one as `keys/NN.png`.
3. **Add the crew.** For every frame that has workers, attach its key and use
   the crew prompt below with that frame's action. Save it as
   `frames/NN.png`. A frame without workers is just its key: copy it across.
4. **Tell me when `frames/` is full.** I line the frames up, build them and
   check the page. The service page picks up the timelapse automatically.

## Rules that worked on the ADU

- **A new chat for every image.** Attach the image you're editing first,
  then `brand-reference.png` when workers are involved.
- **Name what's there and what replaces it.** "Replace the quartz countertops
  with bare cabinet tops" works. "Remove the countertops" often doesn't.
  Gemini adds things reliably but resists undoing finished work.
- **If a key won't go back a stage, build it forward instead.** Attach the
  key *before* it and describe what gets added.
- **Compare every key with the one before it** by flipping between them in
  Windows Photos. Only the job should change. If the camera, windows or view
  moved, redo it, because every later key inherits the mistake.
- **To control an exact shape, put it in the picture yourself.** Gemini
  ignores drawn outlines and red-tinted areas. Ask me and I'll paste the
  shape in.
- **Too polished?** Reply: "Make it look like an ordinary unedited photo:
  flatter light, true colors, slight noise."

## The crew prompt

Attach the frame's **key** first, then `brand-reference.png`. Replace the
`[ACTION]` line with the frame's action from its PROMPTS file.

```
Edit the first image. It is one frame from a fixed construction time-lapse camera, so the camera must not move: keep the exact framing, angle, lens and 16:9 size, and keep everything in the scene exactly as it is. Only add people:

[ACTION]

The workers wear plain black short-sleeve t-shirts printed with the HB Links logo from the second image (small on the chest, large on the back), gray or tan work pants, work boots and safety glasses, plus white hard hats when outdoors. Use the second image only for the shirt print. Keep them toward the sides of the frame, not covering the main view and not close to the camera, in natural mid-task poses with slight motion blur, like a candid time-lapse frame. No other text or logos anywhere. It must still look like an ordinary, unedited photo — not a 3D render.
```

## Building one (I usually run this)

```
node scripts/hero-ai/align.mjs kitchen-remodel
npm run hero-frames -- scripts/hero-ai/kitchen-remodel/aligned --name kitchen-remodel --frames 100 --format avif
```

`align.mjs` locks every frame to the last frame's camera. `hero-frames`
writes the frames to `public/hero/<sequence>` and adds the sequence to
`src/data/heroSequences.json`. The page with that slug then plays it in
place of its photo. The opening frame and the push-in focus can be tuned per
sequence in `src/data/heroBuild.js`.
